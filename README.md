# El Paraíso Coffee Lab

Sitio estático bilingüe (EN/ES) con las postales de preparación para imprimir.

```
index.html              página principal
postcards/
  postales-en.pdf       las 4 postales, 8 páginas (frente y reverso)
  postales-es.pdf
  en/  es/              imágenes PNG sueltas, 6 × 4 in a 300 dpi
```

Los botones de descarga están en la sección "Download for printing" de `index.html`.
No necesita build ni dependencias. Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
